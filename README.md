# MarketParser

MarketParser - консольное приложение на C# для сбора информации о товарах с Яндекс Маркета по поисковому запросу. Программа открывает браузер через Selenium, загружает результаты поиска, переходит в карточки товаров, извлекает основные данные и сохраняет итоговый отчет в Excel.

## Возможности

- поиск товаров на Яндекс Маркете по введенному запросу;
- автоматическая прокрутка выдачи и сбор найденных карточек;
- удаление дублей по ссылкам на товары;
- сбор цены, описания, артикула Маркета и характеристик товара;
- сбор информации о продавце: название магазина, ссылка, юридическое название, ИНН, ОГРН/ОГРНИП;
- сохранение результата в `.xlsx`-файл;
- фиксация ошибки обработки для отдельных товаров, если карточку не удалось разобрать.

## Технологии

- .NET 8
- C#
- Selenium WebDriver
- ChromeDriver / Selenium Manager
- DocumentFormat.OpenXml

## Требования

- Windows, Linux или macOS с установленным .NET SDK 8.0+
- установленный Google Chrome или совместимый Chromium-браузер
- доступ к интернету

## Установка и запуск

1. Склонируйте репозиторий:

```bash
git clone https://github.com/<your-username>/MarketParser.git
cd MarketParser
```

2. Восстановите зависимости:

```bash
dotnet restore
```

3. Запустите приложение:

```bash
dotnet run --project MarketParser
```

4. Введите поисковый запрос в консоли, например:

```text
Введите поисковый запрос: смартфон samsung
```

После запуска откроется окно Chrome. Приложение соберет данные из поисковой выдачи и карточек товаров, затем создаст Excel-файл с результатами.

## Результат

Отчеты сохраняются в папку `outputs` рядом с исполняемым файлом приложения:

```text
MarketParser/bin/Debug/net8.0/outputs/
```

Имя файла формируется автоматически:

```text
market_<поисковый_запрос>_<дата_и_время>.xlsx
```

В отчете есть базовые колонки:

- название из поиска;
- цена;
- ссылка на товар;
- артикул Маркета;
- описание;
- название магазина;
- ссылка на магазин;
- юридическое название продавца;
- ИНН;
- ОГРН/ОГРНИП;
- поисковый запрос;
- заголовок страницы товара;
- ошибка обработки.

Дополнительно в Excel добавляются отдельные колонки для найденных характеристик товаров.
